COMPARATIVE ESSAY ON GITHUB AND WORDPRESS

Github

While coding these websites, I have gained a better understanding of GitHub and how it works in website development. One of Githubs advantages is that is provides a hands on code based approach to website development. However this approach is challenging for beginners, as I have experienced when I was first learning to use Github. Github requires users to manage their HTML files very carefully with very little guidelines. While GitHub grants you a greater control over structure and functionality it introduces many challenges. Using GitHub effectively requires am understanding of HTML and CSS as well as great attention to detail. Through my experience I have recognized I need to improve my attention to detail. I would also like to explore incorporating multimedia into my websites, although I am struggling greatly with this process. Despite these problems github offers opportunities to create website opportunities like the heat map in the Mary Shelly website. However I found that achieving an aesthetically pleasing design through github can be almost impossible.

WordPress

I started working with WordPress after gaining experience with GitHub, and I have found WordPress to be more accessible and a more enjoyable platform. It was initially confusing to navigate but I became more comfortable with its features as I gained experience and played around with the website. One of WordPress’s advantages is its organizational interface. The ability to view the code and the preview of the webpage makes it much easier to understand how changes will affect the final product. WordPress may not be as direct in coding as Github, however it offers a more straightforward approach. Its interface allows the developer to focus on content and visual presentation.

Conclusion

Comparing github and WordPress has demonstrated that each website has different advantages depending on the developers goals. Github emphasizes the technical aspects of developing your page by having the developer work directly with the HTML and CSS files. This approach provides greater control over the web structure. However these benefits also can become the problem themselves. Especially when it comes to file management and creating a visually appealing design. In contrast WordPress provides a more accessible and organized environment that allows the developer to prioritize content and visual presentation without relying on the develops coding knowledge. After creating these websites I prefer WordPress because of the organization of the website itself. i believe that WordPress allows me to focus more on creating a website that I am confident and proud of. This does not mean that learning GitHub isn’t important. Working with GitHub helped me to understand the importance of the code behind the website, and I believe that WordPress presents us with the perfect mixture of the two.
